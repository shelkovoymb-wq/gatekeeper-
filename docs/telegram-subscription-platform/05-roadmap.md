# 05 — Дорожная карта

## Фаза 0 — Фундамент (1 неделя)

- Репозиторий-монорепо: `apps/api` (NestJS), `apps/web` (Next.js), `packages/shared` (типы/контракты).
- Docker Compose: api, web, postgres, redis (+ ваш существующий n8n снаружи).
- CI: lint, typecheck, тесты, build; миграции Drizzle.
- Домены: `api.<домен>`, `app.<домен>`; TLS через Traefik/Certbot.

## Фаза 1 — MVP (4–6 недель): «один клиент может зарабатывать»

Цель: полный цикл подписчика на боте платформы, минимальный кабинет.

- [ ] Auth: регистрация клиента (e-mail + Telegram Login), роли owner/client.
- [ ] Подключение канала: бот платформы админом, `my_chat_member`, проверка прав.
- [ ] Клиентские тарифы: CRUD (цена, период, grace, каналы).
- [ ] Платежи v1: **ЮKassa** (разовые + автоплатёж) и **Telegram Stars** (подписка 30 дней).
- [ ] Статусная машина + reaper + очередь access (approve/kick) + reconciliation.
- [ ] Join-request flow, deep-link `?start=plan_<id>`, оплата в боте.
- [ ] Кабинет клиента: подписчики (список, поиск, ручные выдать/продлить/кикнуть), тарифы, простая статистика.
- [ ] Суперадминка v0: список клиентов, платформенные тарифы (CRUD с JSONB-лимитами), enforcement лимитов.
- [ ] Outbox → n8n: события + 3 workflow (dunning, welcome, алерты в `shmb_n8n_error_bot`).

**Критерий готовности:** тестовый клиент продал подписку, подписчик вошёл по join request, при неоплате был кикнут автоматически, клиент увидел это в кабинете.

## Фаза 2 — v1 (4–6 недель): «продукт для многих клиентов»

- [ ] **Bot-per-client**: подключение своего токена, мульти-webhook, health-check ботов.
- [ ] Trial-периоды, промокоды, несколько каналов на тариф.
- [ ] CloudPayments + CryptoBot.
- [ ] Mini App подписчика (витрина, «мои подписки», продление).
- [ ] Онбординг-мастер клиента + n8n-цепочка дожима.
- [ ] Платформенный биллинг: инвойсы, оплата абонплаты, past_due → suspend.
- [ ] Аналитика клиента: MRR, churn, LTV, источники (deep-link метки).
- [ ] Дашборд владельца: сводный MRR, health платформы.

## Фаза 3 — v2 (по мере роста)

- [ ] White-label: брендинг кабинета, свой домен Mini App.
- [ ] Публичный API + вебхуки для клиентов (интеграции с их CRM).
- [ ] Контент-фичи: отложенные посты в каналы, приветственные серии.
- [ ] Партнёрская программа (рефералы клиентов).
- [ ] Групповые чаты с модерацией, комбо «канал+чат».
- [ ] Экспорт/импорт подписчиков (миграция клиентов с Tribute/InviteMember — понадобится ручная выдача доступов пачкой).
- [ ] Read-реплика Postgres для аналитики; партиционирование `payments`.
